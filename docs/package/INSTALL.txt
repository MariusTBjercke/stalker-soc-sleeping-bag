Sleeping Bag for S.T.A.L.K.E.R.: Shadow of Chornobyl - Enhanced Edition
Version {{VERSION}}

You get a reusable Sleeping bag in your inventory. Use it to rest for 1, 3
or 9 hours, or "Sleep until healed". Resting is refused while you talk, bleed,
are heavily irradiated, or right after taking damage. Damage, or losing health
to hunger or radiation, wakes you at once without healing you. The bag comes
back after every use. It works in new games and in existing saves.

Supported build: Steam, xrEngine.exe 1.10.3+68-42 (Steam build 24067120).
Other builds are refused on purpose.

What you need
  - Windows PowerShell 5.1 (included with Windows 10 and 11). Nothing else.

Install
  1. Extract this archive to any folder, NOT into the game folder.
  2. Open PowerShell in that folder and look at what will change. Nothing is
     written yet:

       powershell -NoProfile -ExecutionPolicy Bypass -File tools\deploy.ps1 -GameDir "<game folder>"

     <game folder> is the one that contains xrEngine.exe.
  3. If the plan looks right, run the same command with -Apply added at the
     end. A backup of every file it replaces goes to out\backups\.
  4. Start the game.

What the installer changes
  - Adds the mod's own files under gamedata\ (scripts, item, menu, texts).
  - Adds one include line to gamedata\config\system.ltx and five short hook
    lines to gamedata\scripts\bind_stalker.script. Every added line ends in
    "-- soc_sleeping_bag" or "; soc_sleeping_bag". The rest of those files,
    including your own edits, is left as it is.
  - Adds gamedata\textures\ui\ui_icon_equipment.dds: the game's own icon
    atlas with only the bag's icon added. If another mod already provides that
    file, the installer stops instead of overwriting it.
  - Writes gamedata\soc_sleeping_bag_deployed.json, a record of what it did.

Uninstall
  Run the same folder's tools\uninstall.ps1 with -GameDir, once without and
  once with -Apply. It removes the mod's files and the marked lines, and keeps
  any mod file you have edited since installing.

Details, supported build, and coexistence: README.md and docs\COMPATIBILITY.md.
