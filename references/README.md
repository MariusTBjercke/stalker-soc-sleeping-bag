# Local reference material

`references/` is ignored except for this policy file. It may contain local
game extracts, third-party mods, research notes, and tools needed for
inspection. Do not copy material from this directory into source files and do
not commit its contents. In particular, do not copy or redistribute ABC
Sleeping Bag Mod code, XML, textures, or icon atlases.

The installed game directory is also an input location. It is not a source
tree and must be changed only by reviewed deployment commands.
